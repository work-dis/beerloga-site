# БИРЛОГА

Информационный сайт сети физических магазинов напитков и закусок в Бресте.
Сайт показывает категории, демонстрационные цены и наличие, адреса, телефоны,
режим работы и ссылки на маршруты. Это **не интернет-магазин**: корзина,
онлайн-заказ, оплата, доставка и обязательное бронирование отсутствуют.

> Технические меры в проекте не являются гарантией полного соответствия
> законодательству. Перед публичным запуском сайт и весь фактический контент
> должны пройти отдельную юридическую проверку в Республике Беларусь.

## Стек

- Next.js 16.2.12, App Router, TypeScript;
- React 19.2.6, Server Components по умолчанию;
- небольшие Client Components только для меню и каталога;
- Tailwind CSS 4.2.1 через PostCSS, без CDN;
- `next/font`, `next/image`, Lucide;
- Vitest не используется: серверные проверки выполняются Node Test Runner;
- Playwright проверяет поведение и размеры на реальных браузерных движках;
- vinext/Vite формирует Cloudflare Workers-совместимую production-сборку.

## Установка и запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Локальный адрес по умолчанию: `http://localhost:3000`.

Production-сборка:

```bash
npm run build
npm run start
```

Проверки:

```bash
npm run lint
npm test
npm run test:e2e
```

Для первого локального запуска E2E может потребоваться:

```bash
npx playwright install chromium
```

## Данные

Модели `Product`, `Store` и связанные типы находятся в
`src/data/types.ts`.

Товары добавляются в `src/data/products.ts`. Для каждого товара нужен уникальный
`id` и `slug`, категория, валюта `BYN`, дата обновления и наличие по идентификаторам
магазинов. Для пива допустимы только нейтральные справочные поля. Сидр, медовуха,
вино, ликёры и крепкий алкоголь не должны попадать в пивной каталог.

Магазины добавляются в `src/data/stores.ts`. Перед публикацией требуется заменить
адрес, телефон, координаты, режим работы, ссылку на карту и фотографию.

### Демонстрационные данные

- четыре позиции пива: «Чешский ёжик», «Ирландский эль»,
  «Пшеничное светлое», «Безалкогольное 0,0%»;
- безалкогольные напитки, снеки, сыр и пакет;
- три магазина с вымышленными адресами и телефонами;
- все цены, наличие и дата обновления;
- электронная почта `info@example.by`;
- предполагаемый canonical-домен `https://beerloga.by`.

Все контактные демонстрационные значения отмечены комментариями `TODO`.
Canonical-домен задаётся переменной `NEXT_PUBLIC_SITE_URL`.

## Поиск и фильтры

Каталог фильтруется в браузере без сетевых запросов. Поиск:

- нечувствителен к регистру;
- считает `ё` и `е` эквивалентными;
- убирает крайние и повторяющиеся пробелы;
- ищет по названию, производителю, стране и виду;
- показывает доступное пустое состояние.

Состояние синхронизируется с query parameters `q`, `category`, `country`,
`strength`, `volume`, `store`. Прямая ссылка восстанавливает фильтры, а
`popstate` восстанавливает состояние при навигации назад/вперёд. На мобильных
фильтры открываются в нативном доступном `dialog`; после закрытия фокус
возвращается на кнопку.

## Изображения

- `public/images/store-interior.webp` — созданный специально для проекта
  нейтральный пустой интерьер без людей и животных;
- `public/og.png` — фирменная карточка 1200×630 для Open Graph;
- карточки товаров используют кодовые нейтральные силуэты упаковки, без сцен
  употребления и эмоциональных образов.

При замене изображений:

1. подтвердить права на публикацию;
2. исключить людей, животных, персонажей, вечеринки и сцены употребления;
3. не добавлять спортивные образы, призывы или заявления о пользе;
4. сохранить WebP/AVIF, разумный размер файла и корректный `alt`;
5. проверить мобильный и десктопный crop.

  [постановление №317](https://pravo.by/document/?guid=3871&p0=c20600317).

Статьи 17–18 Закона №225-З запрещают в соответствующей рекламе образы людей и
животных, связь употребления с успехом или состоянием, заявления о пользе,
безвредности или утолении жажды, призывы к употреблению и дискредитацию
воздержания. Для рекламы пива требуется предупреждение о вреде чрезмерного
употребления площадью не менее 10% рекламы и постоянное отображение в
мультимедийной рекламе.

### Расхождение в исходном задании

Предоставленная ссылка на постановление №317 возвращает 404. Само постановление
№317 от 06.03.2006 утратило силу с принятием постановления №363 от 25.06.2021.
Поэтому старые положения №317 не перенесены в код как действующие. Юристу следует
определить актуальные нормы розничной торговли, включая местные решения Бреста,
непосредственно перед публичным запуском.

### Расчёт площади предупреждения

Рекламный контейнер определён явно компонентом `BeerAdvertisingSection` и
атрибутом `data-testid="beer-advertising-section"`. Предупреждение —
`BeerLegalWarning` с `data-testid="beer-legal-warning"`.

Измерительный тест вычисляет:

```text
ratio = (warning.width × warning.height) /
        (advertising.width × advertising.height)
```

и требует `ratio >= 0.10`. Контейнер намеренно ограничен вводным рекламным
блоком; каталог ниже является отдельной справочной областью. Предупреждение
находится вне фильтров и списка результатов, поэтому остаётся видимым после
поиска, смены магазина и в пустом состоянии.

Зафиксированные значения:

| Контрольный размер | Доля предупреждения |
| --- | ---: |
| 320×568 | 34,73% |
| 375×812 | 35,24% |
| 390×844 | 35,25% |
| 768×1024 | 38,67% |
| 1024×768 | 28,94% |
| 1440×900 | 28,96% |

## SEO и доступность

- уникальные title, description, canonical и Open Graph для всех страниц;
- `robots.ts`, `sitemap.ts`, favicon и Open Graph image;
- JSON-LD только `LocalBusiness`, `Store`, `PostalAddress` и
  `OpeningHoursSpecification`; `Product`/`Offer` для алкоголя отсутствуют;
- один H1, семантические landmarks, skip-link, видимый `focus-visible`;
- интерфейс работает с клавиатурой и `prefers-reduced-motion`;
- поля имеют подписи, количество результатов объявляется через `aria-live`;
- наличие передаётся текстом и цветовым индикатором;
- цели не меньше 44×44 CSS px, соседние мобильные цели разделены минимум 8 px;
- мобильная нижняя панель учитывает `env(safe-area-inset-bottom)`;
- базовый мобильный текст 16 px и масштабирование не заблокировано.

## Ограничения

- фактические адреса, контакты, цены и наличие не предоставлены;
- статус «Открыто/Закрыто» не вычисляется для демонстрационных магазинов:
  отображается честное «Статус уточняется по телефону»;
- нет CMS: данные обновляются в TypeScript-файлах;
- нет аналитики, cookie-трекеров, сторонних API и сбора персональных данных;
- локальная Workers-сборка использует `next/image` с явными размерами и
  оптимизированным WebP, но отключает runtime image proxy (`unoptimized`),
  чтобы не зависеть от серверной обработки изображений;
- фактические Lighthouse-показатели зависят от production-хостинга и должны
  быть повторно измерены после подключения реального домена.
